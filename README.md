Othello for Android
Source recovered from an old Eclipse ADT project, part of the Android resources and project metadata are missing.

A small Othello/Reversi game written in Java for early Android devices.

Background
This project was developed with Eclipse ADT around 2012-2014 and is preserved here as a historical experiment.

The AI uses a simple heuristic evaluation and random choice among equally scored moves.

Status
Unmaintained. The code is provided for historical and educational purposes.

Build
The original project was built using Eclipse ADT. Migration to Android Studio would probably require some adjustments.
